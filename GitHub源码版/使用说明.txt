高德 GCJ-02 → WGS-84 通用转换工具 v2.1
=========================================

一、启动程序

双击“AMap_GCJ02_to_WGS84_GUI.exe”。
必须保留 EXE 和 _internal 文件夹的相对位置，请勿只单独复制 EXE。


二、转换步骤

1. 点击“选择源文件夹…”，选择扩展名为 .gdb 的 Esri FileGDB 文件夹；
2. 点击“选择输出…”，填写新的 .gdb 或 .gpkg 输出名称；
3. 点击“开始转换”；
4. 完成后可点击“打开输出文件夹”。

也可以直接在输入框中粘贴源文件和输出路径。程序不预设任何源文件地址。


三、转换内容

1. 自动转换源 GDB 中的全部 Point 点图层；
2. 点几何由高德 GCJ-02 逆算为 WGS-84；
3. 如果存在 lon/lat、lng/latitude 或中文经纬度字段，会同步转换；
4. 新增 gcj02_lon、gcj02_lat 字段，保留原始坐标；
5. 保留其他属性，并支持现代 FileGDB 的 Integer64 字段；
6. 输出图层标记为 WGS-84 / EPSG:4326；
7. 在输出旁生成 *_conversion_report.json 核验报告；
8. 源 FileGDB 永远不会被修改。


四、已有输出

程序默认不会覆盖已有输出。
勾选“备份并替换已有输出”后，旧输出会被自动改名备份，再写入新结果。


五、适用范围与注意事项

1. 仅用于已确认是高德 GCJ-02 的中国境内 POI 点数据；
2. 不要转换已经是 WGS-84 的数据；
3. 当前版本只处理 Point 点图层，非点图层不会写入输出；
4. 这是非官方数值逆算，高德官方不提供 GCJ-02 转 WGS-84 接口；
5. POI 可能代表建筑中心或入口，坐标系转换不能消除 POI 本身的位置误差；
6. 使用 Integer64 FileGDB 输出时，建议使用 ArcGIS Pro 3.2 或更高版本；
7. 对外发布或用于测绘成果前，请确认数据授权、平台条款和测绘合规要求。
